# Versão em Português
Repositório criado para armazenar estudos sobre C/C++. Ele contêm programas aleatórios, anotações sobre as linguagens e programas como calculadoras em C.

## Diretórios  
1. Programas - Teste :
   - São programas que foram escritos para testa alguma parte da linguagem em que foram escritos.
2. Calculadora :
   - Esse diretório possui várias versões de uma calculadora em C, algumas dessas sendo feitas com input em arquivos, os quais estão dentro da pasta da versão/program.files.
3. Jogo em C :
   - Esse diretório contém várias versões de um simples jogo em C. Algumas versões são jogadas dentro do terminal, enquanto outras são jogadas em arquivo, o qual estará disponivel no diretório da versão/program_files.

# English version

Repository created to document my C/C++ studies. It contais ramdom programs, notes about the C/C++ and programs such as calculators in C.
##  Directories 
1. Programas - Teste :
   - This directory houses programs that were written in order to test some part of the language they were written in.
2. Calculadora : 
   - This directory contains many version of a calculator in C, some of witch make use of a file in order for the user to input numbers and operations. These files have been provided in the version folder/program.files.
3. Jogo em C :
   - This directory contains many version of a simple game in C. Some versions are played in the terminal, while others are played in a file, which will be provided in the version folder/program_files.
