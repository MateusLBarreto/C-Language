# C-Language
- Esse README está disponível em Inglês e Português.
- This README is available in both English and Brasilian Portuguese.

Repositório criado para armazenar estudos sobre C/C++. Ele contêm programas aleatórios, anotações sobre as linguagens e programas como calculadoras em C.
Repository created to document my C/C++ studies. It contais ramdom programs, notes about the C/C++ and programs such as calculators in C.

## Diretórios / Directories
1. Programas - Teste :
   - São programas que foram escritos para testa alguma parte da linguagem em que foram escritos.
   - This directory houses programs that were written in order to test some part of the language they were written in.
2. Calculadora :
   - Esse diretório possui várias versões de uma calculadora em C, algumas dessas sendo feitas com input em arquivos, os quais estão dentro da pasta da versão.
   - This directory contains many version of a calculator in C, some of witch make use of a file in order for the user to input numbers and operations. These files have been provided in the version folder.
